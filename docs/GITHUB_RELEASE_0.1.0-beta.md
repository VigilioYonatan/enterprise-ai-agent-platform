```markdown
## AgentOps `v0.1.0-beta` (Public Beta)

Build AI assistants, connect them into visual workflows, pause sensitive actions for human approval, and search your team's private playbooks — **100% self-hosted on your own machine or server**.

### ✨ What's Included in `0.1.0-beta`
- **Visual Workflow Studio:** Drag-and-drop and keyboard-friendly workflow builder with version history.
- **AI Assistants & Local Test Chat:** Plain-language instructions, saved versions (`v1`, `v2`), and live local AI chat via Ollama.
- **Second-Pair-of-Eyes Approvals:** Sensitive tool actions pause automatically until another workspace owner/admin approves them.
- **Private Team Knowledge Base:** Upload guides, manage read permissions per teammate, and search with source citations.
- **Quality Checks, Usage & Activity Log:** Built-in test benchmarks, local model usage overview, and full workspace activity history.
- **Adaptive Dark & Light Mode:** Seamless dark and light themes across the entire console and brand icons.

### 📦 Quick Download & Run
1. Download **`Source code (zip)`** or **`Source code (tar.gz)`** below (or run `git clone --branch v0.1.0-beta <repo-url>`).
2. Follow the **Download & Get Started** steps in [`README.md`](../../README.md) to open `http://localhost:8080`.

See [`CHANGELOG.md`](../../CHANGELOG.md) for full details.
```
